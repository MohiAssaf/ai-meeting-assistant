# AI Meeting Assistant

AI-powered audio transcription, meeting summarization,
and action-item extraction.

## About

Coursework for Introduction to Artificial Intelligence
Technologies at Technical University of Sofia.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- AI: Speech-to-text and LLM integration

## Project Structure

- `frontend/` - React application
- `backend/` - FastAPI service
- `evaluation/` - AI benchmarking and evaluation
- `docs/` - Architecture and coursework documentation
